# StarWind SW-LED43SG300: свой домашний экран

Ветка `starwind` поверх CleanYourTV. Свой экран: `IosHome` (экран, док, навигация, меню), `IosFeed` (ленты),
`IosIcons` (логотипы), `IosConfig` (ключи сервисов приходят из adb, в APK их нет).

Всё делается одной командой `starwind/tv`, справка без аргументов.

Не в репозитории: `~/Documents/Claude/secrets.json` (ключи Google и Кинопоиска), шрифты SF (из архива
владельца при сборке), значки SF Symbols (рисует `icons.swift` на Mac; запасные лежат в `fallback/`).

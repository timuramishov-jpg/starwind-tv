# Если что-то не так

| Проблема | Что сделать |
|---|---|
| `tv`: «телевизор не отвечает» | Телевизор включён и в той же сети? Адрес не сменился (`~/Documents/Claude/tv-ip`)? Отладка включена (Настройки → Для разработчиков)? Закрепите адрес в роутере |
| Телевизор просит «Разрешить отладку?» | Разрешить и отметить «Всегда». Без этого `tv` и пульт (часть функций) не работают |
| Пульт не открывается | Телефон в той же Wi‑Fi сети? Открыть QR заново (адрес мог смениться). Если не помогло — `tv deploy` перезапустит сервер пульта |
| Пульт открылся, кнопки не работают | Сервер мог остаться от старой версии: `QUIET=1 tv deploy` |
| На пульте не появляется поле ввода | Включена ли своя клавиатура (пульт → Инструменты → «Своя клавиатура»)? В YouTube поле не появляется — там поиск через лупу пульта |
| Ленты YouTube/Кинопоиска пустые | Нет ключей: `secrets.json` и `tv keys` ([INSTALL.md](INSTALL.md#шаг-4-ключи-сервисов-необязательно)). YouTube подписки — войти: пульт → Аккаунты → YouTube |
| Главный экран подвисает или «откатывается» | Не хватает памяти: `tv lighten`, плитка «Очистить память», закрыть тяжёлые приложения. `tv report` покажет, кто занимает память |
| Telegram «Нет VPN» | Так задумано: Telegram только через VPN. Включить Happ |
| Telegram: видео долго стартует | Задержаться на карточке пару секунд перед ОК (видео готовится заранее). Проверить скорость VPN (экран Happ) |
| Telegram: «Ключ не подошёл» | Проверить api_id (число) и api_hash (32 символа a–f, 0–9) с my.telegram.org |
| Не сохраняется в «Фото» | Установлена ли команда «Starwind в Фото» и включено «Сразу сохранять в Фото»; при первом запуске разрешить доступ к Фото и локальной сети |
| После `tv deploy`: `UPDATE_INCOMPATIBLE` | Сборка подписана другим ключом (потерян `starwind.jks`). Согласиться на переустановку — настройки вернутся из копии |
| Нужно вернуть Яндекс | `tv rollback` (наш лаунчер останется, но не будет домашним экраном) |
| Сборка падает | Лог — `~/Documents/Claude/build.log`; тесты — `test.log`. Частое: нет JDK 17/SDK — `tv setup` |
| Заставка не включается | Пульт → Инструменты → «Заставка через»; на главном экране простой должен быть дольше задержки |
| Таймер сна не гасит экран | `tv deploy` выдаёт права администратора (`dpm set-active-admin`); проверить, что не было ошибки |

# Установка с нуля

Как повторить Starwind на другом телевизоре. Всё делается с Мака по домашней сети; на телевизоре ничего не
прошивается и не удаляется: свой домашний экран ставится как обычное приложение, лишнее от Яндекса только
выключается, и одна команда возвращает всё как было (`tv rollback`).

## Что понадобится

| | Требования |
|---|---|
| Телевизор | Проверено на **StarWind SW-LED43SG300** (Яндекс ТВ, Android 11, MediaTek, armeabi-v7a, 1 ГБ памяти). Подойдёт другой телевизор на Android TV / Яндекс ТВ с Android 8+ и процессором ARM. На другой модели могут отличаться имена пакетов Яндекса (`tv slim`) и пункты системных настроек. |
| Мак | macOS 12+ (Apple Silicon или Intel), [Homebrew](https://brew.sh), около 5 ГБ места (Android SDK и сборка). |
| Сеть | Мак, телевизор и телефон — в одной домашней сети Wi‑Fi. |
| Телефон | Любой с браузером для пульта; сохранение снимков в «Фото» и иконка на экране «Домой» — для iPhone. |
| Необязательно | Ключи YouTube и Кинопоиска (ленты сервисов), ключ Telegram API (свой клиент Telegram), подписка VPN в Happ. |

## Шаг 1. Телевизор: включить отладку по сети

1. На телевизоре: **Настройки → Устройство → Об устройстве**, семь раз нажать на «Сборка» — включится режим разработчика
   (на других прошивках путь может немного отличаться: ищите «Об устройстве» и номер сборки).
2. **Настройки → Устройство → Для разработчиков**: включить **Отладка по USB** и, если есть, **Отладка по сети**.
   На SW-LED43SG300 отладка по сети на порту 5555 открыта сразу после этого.
3. Узнать адрес телевизора: **Настройки → Сеть → Wi‑Fi → (своя сеть)**, например `192.168.1.50`.
   Лучше закрепить этот адрес за телевизором в настройках роутера (резервирование DHCP), чтобы он не менялся.
4. При первом подключении с Мака телевизор спросит «Разрешить отладку?» — нажать «Разрешить» и отметить «Всегда».

Подробнее о подключении и частых проблемах — [`docs/TROUBLESHOOTING.md`](../../docs/TROUBLESHOOTING.md#connecting)
(из CleanYourTV) и [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## Шаг 2. Мак: забрать проект и подготовить инструменты

```bash
mkdir -p ~/Documents/Claude
git clone https://github.com/timuramishov-jpg/starwind-tv.git ~/Documents/Claude/cleanyourtv
~/Documents/Claude/cleanyourtv/starwind/tv setup
```

`tv setup` один раз ставит через Homebrew Java 17, Android SDK (platform 34, build-tools 34), GitHub CLI, создаёт
окружение Python для связи с телевизором (`tools/venv`), спрашивает адрес телевизора (сохраняет в
`~/Documents/Claude/tv-ip`) и делает команду `~/Documents/Claude/tv`.

Рабочая папка по умолчанию — `~/Documents/Claude` (ключи, снимки, журналы, копии настроек). Другую можно задать
переменной `STARWIND_HOME`, адрес телевизора на один запуск — переменной `TV_IP`.

## Шаг 3. Шрифты SF Pro (рекомендуется)

Весь интерфейс рассчитан на SF Pro. В репозиторий шрифты Apple не входят (лицензия Apple).

- Положить в рабочую папку архив шрифтов SF с именем вида `SF-NF-*.zip` (внутри — `SF NF 17.0d11e1/TTF/SFNS-*.ttf`);
  `tv deploy` сам возьмёт из него Light/Regular/Medium/Semibold и широкое начертание для заставки.
  Шрифты SF Pro бесплатно скачиваются на [developer.apple.com/fonts](https://developer.apple.com/fonts/).
  Если архив другой структуры, достаточно руками положить четыре файла в `launcher/app/src/main/res/font/`
  (`sf_light.ttf`, `sf_regular.ttf`, `sf_medium.ttf`, `sf_semibold.ttf`).
- Скруглённые цифры заставки берутся с Мака: `/System/Library/Fonts/SFNSRounded.ttf` (или `~/Documents/Claude/sfx/SFNSRounded.ttf`).
- Значки шапки рисуются из SF Symbols на Маке (`starwind/icons.swift`, нужен `xcode-select --install`);
  без Swift используются готовые из `starwind/fallback/`.

Без архива сборка всё равно пройдёт — с прежними файлами шрифтов из репозитория.

## Шаг 4. Ключи сервисов (необязательно)

Файл `~/Documents/Claude/secrets.json` — **никогда не кладётся в git**. `tv deploy` передаёт ключи на телевизор по adb,
в APK их нет.

```json
{
  "installed": { "client_id": "….apps.googleusercontent.com", "client_secret": "…" },
  "api_key": "AIza…",
  "kinopoisk_key": "…"
}
```

| Ключ | Зачем | Где взять |
|---|---|---|
| `installed.client_id`, `installed.client_secret` | Вход в YouTube на телевизоре (лента подписок) | [Google Cloud Console](https://console.cloud.google.com/): проект → APIs & Services → включить **YouTube Data API v3** → Credentials → OAuth client ID, тип **TVs and Limited Input devices**; скачанный JSON как раз имеет вид `{"installed": …}` |
| `api_key` | Популярное YouTube и поиск без входа | Там же: Credentials → API key |
| `kinopoisk_key` | Лента и поиск Кинопоиска | [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech) — бесплатный ключ после регистрации |

Без ключей лаунчер работает: ленты YouTube и Кинопоиска будут пустыми, остальное — как обычно.
Передать ключи заново: `tv keys`. Рутуб, погода (Open‑Meteo) и ВК ключей не требуют.

## Шаг 5. Собрать и поставить

```bash
~/Documents/Claude/tv deploy
```

Что делает `deploy` (подробно — [DEVELOPMENT.md](DEVELOPMENT.md#tv-deploy-по-шагам)):

1. Проверяет, что телевизор в сети, и шрифты/значки/библиотеку Telegram.
2. Прогоняет тесты дизайн-системы и разборщиков (`starwind/test/run.sh`) — без них не собирает.
3. Собирает APK (`./gradlew assembleRelease`), подписывает своим ключом `~/Documents/Claude/starwind.jks`
   (создаётся при первой сборке; хранить его — иначе следующая сборка не встанет поверх без переустановки).
4. Ставит APK на телевизор и выдаёт права: настройки, администратор для таймера сна, заставка, установка обновлений,
   своя клавиатура, быстрые анимации.
5. Запускает сервер пульта, делает лаунчер домашним экраном, передаёт ключи и показывает отчёт.

## Шаг 6. Убрать Яндекс с глаз и разгрузить память

```bash
~/Documents/Claude/tv slim        # выключить оболочку Яндекса, его эфир и видеоплеер (не удаляет)
~/Documents/Claude/tv lighten     # запретить фон лишним приложениям; вернуть: tv lighten off
```

`tv rollback` возвращает оболочку Яндекса домашним экраном. Полная очистка Android TV по правилам CleanYourTV — в
[`PROMPT.md`](../../PROMPT.md) (на этом телевизоре понадобился только `tv slim`).

## Шаг 7. Приложения

Док по умолчанию: YouTube (`com.yandex.tv.ytplayer`), ВК, Рутуб, Кинопоиск, Happ (VPN); Зона — если установлена. Telegram — плитка
в ряду приложений (появляется после ввода ключа). Поставить APK с Мака: `tv install файл.apk`, с телефона — пульт → «Инструменты» →
«Отправить на телевизор». Магазины: `tv aurora` (Aurora Store) или RuStore.

| Приложение | Зачем | Пакет |
|---|---|---|
| Happ | VPN для всего телевизора (лаунчер управляет им из меню и пульта) | `su.happ.proxyutility` |
| ВК Видео, Рутуб | Ленты в доке | `com.vk.tv`, `ru.rutube.app.tv` |
| Зона | Фильмы | `ru.zonaplayer.app` |

## Шаг 8. Пульт в телефоне

На главном экране телевизора — значок телефона вверху справа: появится QR-код. Открыть его камерой телефона, страница
откроется в браузере. На iPhone: «Поделиться» → «На экран „Домой“» — появится иконка-приложение. Подробно — [REMOTE.md](REMOTE.md).

## Шаг 9. Telegram (необязательно)

Нужен свой ключ API с [my.telegram.org](https://my.telegram.org) → API development tools. С российским номером сайт часто
отвечает ошибкой: помогает VPN через Казахстан (или Узбекистан) и повтор через несколько часов. Ключ вводится в пульте:
«Аккаунты» → Telegram, вход — по QR-коду на телевизоре. Подробно — [TELEGRAM.md](TELEGRAM.md).

## Что хранить отдельно (в git этого нет)

| Файл | Зачем | Если потерять |
|---|---|---|
| `~/Documents/Claude/secrets.json` | Ключи YouTube и Кинопоиска | Создать новые (шаг 4) |
| `~/Documents/Claude/starwind.jks`, `starwind.pass`, `starwind.alias` | Подпись сборок | Новая сборка не встанет поверх старой: `tv deploy` предложит переустановить (настройки сохранит из копии) |
| Архив шрифтов SF | Шрифты интерфейса | Скачать заново (шаг 3) |
| Ключ Telegram API | Клиент Telegram | Взять тот же на my.telegram.org — он не меняется |

Удобно держать эти файлы в личном облаке (iCloud Drive) или менеджере паролей.

## Второй телевизор

Каждому телевизору — свой адрес: `TV_IP=192.168.1.60 ~/Documents/Claude/tv deploy`. Город погоды — в `IosWeather.java` (Москва).

## Обновление из меню телевизора

«Обновить лаунчер» в настройках телевизора берёт сборки из **открытого репозитория релизов владельца** —
`<ваш логин GitHub>/tv-home`. `tv deploy` создаёт его сам при первой сборке и выкладывает туда каждую сборку (только APK,
без ключей). Нужно только один раз войти: `gh auth login`. Другой репозиторий — файл `~/Documents/Claude/releases-repo`
(одна строка `логин/имя`) или переменная `STARWIND_RELEASES`. Не вошли в GitHub — сборка получится без обновления
из меню (пункт скажет «не настроено»), всё остальное работает.

Чужие релизы на ваш телевизор не встанут: сборки подписаны ключом владельца (`starwind.jks`).

# Starwind Design System — правила для ИИ

> Отдай этот файл нейросети целиком вместе с задачей: «Делай интерфейс строго по этому файлу».
> Источник — дизайн-система проекта Starwind TV (лаунчер телевизора + пульт в телефоне). Ориентир — Apple TV / iOS, тёмная тема.

## 0. Главное правило

**Никаких «своих» значений.** Цвет, размер шрифта, скругление, отступ, тень — только токен из этого файла.
Если нужного токена нет — взять ближайший существующий, а не придумывать новый. Если без нового не обойтись —
сначала спросить человека.

## 1. Принципы

1. **Тёмная тема, чёрный фон.** Светлой темы нет. Фон — чистый чёрный, поверх — серые плоскости.
2. **Спокойно и крупно.** Мало элементов на экране, много воздуха, один акцент на экран.
3. **Цвет — только акцентом.** Интерфейс нейтральный (чёрный + серые + белый текст); цвет появляется у выбранного
   элемента, значка, свечения. Один экран — один акцентный цвет.
4. **Фокус всегда виден.** Что выбрано — понятно с трёх метров: белая обводка, увеличение, белая плашка.
5. **Тексты по-русски, коротко, по-человечески.** Без канцелярита и англицизмов, где есть русское слово.

## 2. Цвета

### Нейтрали (только эти)

| Токен | HEX | Назначение |
|---|---|---|
| `black` | `#000000` | Фон экрана |
| `gray6` | `#1C1C1E` | Карточки, панели, листы |
| `gray5` | `#2C2C2E` | Поднятое: кнопки, выбранная плашка в тёмном списке |
| `gray4` | `#3A3A3C` | Дорожки слайдеров, выключенные тумблеры, рамки полей |
| `gray3` | `#48484A` | Разделители |
| `gray2` | `#636366` | Неактивные значки |
| `gray1` | `#8E8E93` | Значки в покое |

### Текст (три уровня + на светлом)

| Токен | HEX | Назначение |
|---|---|---|
| `ink` | `#F5F5F7` | Основной текст; фон выбранной строки меню |
| `secondary` | `#AEAEB2` | Пояснения, подписи |
| `tertiary` | `#6E6E73` | Подсказки, неактивное |
| `on-light` | `#0B0B0D` | Текст на светлой (`ink`) плашке |

### Акценты (цвета iOS, тёмный вариант)

`red #FF453A` · `orange #FF9F0A` · `yellow #FFD60A` · `green #30D158` · `teal #40C8E0` · `blue #0A84FF` ·
`indigo #5E5CE6` · `purple #BF5AF2` · `pink #FF375F`

- Каждому сервису/разделу — **один** акцент из этого набора. Чужой фирменный цвет приводится к ближайшему акценту
  (например, фирменный фиолетовый Twitch `#9146FF` → `purple`).
- Смысловые: успех/включено — `green`, ошибка/опасное действие — `red`, предупреждение — `orange`, ссылка/действие — `blue`.

### Прозрачные слои

| Токен | Значение | Назначение |
|---|---|---|
| `scrim-strong` | чёрный 85% (`#000000D9`) | Под текстом поверх фото |
| `scrim` | чёрный 70% (`#000000B3`) | Затемнение под меню и модальными окнами |
| `scrim-soft` | чёрный 40% (`#00000066`) | Тени, плашки на обложках (длительность) |
| `hairline` | белый 30% (`#FFFFFF4D`) | Тонкая линия по краю выбранного |
| `glass` | белый 12% (`#FFFFFF1F`) | Стеклянная карточка |
| `glow(accent)` | акцент с альфой 47% (`0x77`) | Свечение |
| `tint(accent)` | акцент с альфой 33% (`0x55`) | Подложка под значком/пилюлей |

## 3. Шрифт

**SF Pro** (на Apple — системный `-apple-system`; на Android/вебе без SF — **Inter**). Начертания: Light, Regular,
Medium, Semibold. Жирнее Semibold — нельзя.

Ровно **шесть размеров**, других нет:

| Токен | ТВ (pt в макете 1920×1080) | Телефон / веб (px) | Для чего |
|---|---|---|---|
| `display` | 88 | 44 | Часы, крупный код, главный заголовок экрана |
| `title` | 44 | 22 | Заголовок экрана/панели |
| `headline` | 34 | 17 | Название карточки, пункт меню, основной текст пульта |
| `body` | 30 | 15 | Обычный текст |
| `callout` | 26 | 13 | Подписи, вторичный текст |
| `footnote` | 22 | 11 | Метки, бейджи, мелкие пояснения |

Межстрочный интервал ~1.35. Заголовки — Semibold, текст — Regular, крупные цифры — Light.

## 4. Скругления

| Токен | ТВ | Телефон / веб | Для чего |
|---|---|---|---|
| `r-badge` | 10 | 5 | Бейджи, метки |
| `r-row` | 20 | 10 | Строки списков, поля ввода, кнопки |
| `r-card` | 26 | 13 | Карточки, обложки |
| `r-pill` | 40 | 20 | Пилюли, панели, листы |

## 5. Отступы — сетка 8

| Токен | `s1` | `s2` | `s3` | `s4` | `s5` | `s6` | `s7` |
|---|---|---|---|---|---|---|---|
| ТВ (pt) | 8 | 16 | 24 | 32 | 48 | 64 | 96 |
| Телефон / веб (px) | 4 | 8 | 12 | 16 | 24 | 32 | 48 |

- Поле экрана ТВ — `edge` = 56; всё начинается на одной вертикальной линии.
- На телефоне боковое поле — `s4` (16 px).
- Значение 4 (ТВ) / 2 (телефон) — только для микроподгонки внутри мелких элементов.

**Масштаб:** телефон и веб = ровно **половина** значений ТВ. Цвета одинаковые везде.

## 6. Компоненты и поведение

- **Фокус / выбор.** Карточка — белая обводка 4 pt (`ink`) и увеличение на 5%. Строка меню — белая плашка `ink`,
  текст `on-light`. На тач-устройствах — подсветка `gray5` при нажатии.
- **Свечение сервиса.** Радиальный градиент `glow(accent)` из точки логотипа (ТВ) или от верха экрана (телефон),
  уходит в прозрачный. Один слой; при смене раздела цвет плавно перетекает.
- **Карточка.** Фон `gray6`, скругление `r-card`, обложка 16:9, под ней название `headline` и подпись `callout`
  `secondary`. Длительность — бейдж `footnote` на `scrim-soft` в правом нижнем углу обложки.
- **Панели и листы.** Фон `gray6` (или стекло: `gray6` 82% + размытие 20 px), скругление `r-pill`, внутренний отступ `s5`.
- **Кнопки.** Основная — плашка `ink` с текстом `on-light`; второстепенная — `gray5` с текстом `ink`; опасная — текст
  или плашка `red`. Высота — по сетке, скругление `r-row` (пилюли — `r-pill`).
- **Пилюля действия.** Подложка `tint(accent)`, текст `ink`.
- **Переключатели.** **Два состояния — тумблер** (вкл — `green`, выкл — `gray4`). **Три и больше вариантов —
  выбор**: стрелками ←/→ на ТВ, списком/сегментом на телефоне. Не делать тумблер для выбора из трёх.
- **Поля ввода.** Фон `gray6`, рамка `gray4`, скругление `r-row`, плейсхолдер `tertiary`.
- **Списки.** Строки на `gray6`, разделитель `gray3` толщиной 0.5 px с отступом слева; заголовок группы — `footnote`
  `secondary`, обычными буквами (не прописными).
- **Значки.** SF Symbols (или похожий линейно-заливочный набор), одноцветные: в покое `gray1`, неактивные `gray2`,
  выбранные — акцент. Логотипы сервисов — одноцветные маски, окрашенные акцентом раздела.
- **Модальное.** Затемнение `scrim`, по центру панель. Одно модальное окно за раз.
- **Пустое состояние.** Одна строка `body` `secondary` по сути («Сейчас никто из подписок не в эфире») + одна
  пилюля действия. Без иллюстраций.

## 7. Движение

- Длительности: 160–200 мс — фокус и мелкие переходы, 300 мс — панели и смена разделов, 2,5 с — медленные фоновые
  (перетекание свечения на заставке).
- Кривая — ease-out (замедление в конце). Никаких пружин и отскоков.
- Анимировать только прозрачность, масштаб, сдвиг и цвет. На слабом железе — не больше одного полноэкранного
  анимированного слоя.

## 8. Тексты

- Русский язык, обращение на «ты», как в Apple: «Войди в Twitch», «На телефоне открой twitch.tv/activate».
- Коротко: кнопка — 1–2 слова (глагол: «Войти», «Сохранить», «Открыть»), подпись — одна строка.
- Числа по-русски: «1,5 ГБ», «5 мин», «12 тыс. зрителей», правильные окончания (1 зритель, 3 зрителя, 5 зрителей).
- Без восклицательных знаков, эмодзи и КАПСА.

## 9. Запрещено

- Цвета, шрифты, скругления и отступы вне токенов; инлайн-стили в HTML.
- Белый или светлый фон экрана, градиенты «для красоты», тени кроме `scrim-soft`.
- Больше одного акцентного цвета на экране.
- Жирнее Semibold, курсив, подчёркивание (кроме ссылок в тексте).
- Тумблер для выбора из 3+ вариантов; выпадающий список для двух.

## 10. Готовый CSS (веб / телефон)

```css
:root{color-scheme:dark;
  --black:#000000;--gray6:#1c1c1e;--gray5:#2c2c2e;--gray4:#3a3a3c;--gray3:#48484a;--gray2:#636366;--gray1:#8e8e93;
  --ink:#f5f5f7;--secondary:#aeaeb2;--tertiary:#6e6e73;--on-light:#0b0b0d;
  --red:#ff453a;--orange:#ff9f0a;--yellow:#ffd60a;--green:#30d158;--teal:#40c8e0;--blue:#0a84ff;--indigo:#5e5ce6;--purple:#bf5af2;--pink:#ff375f;
  --scrim-strong:#000000d9;--scrim:#000000b3;--scrim-soft:#00000066;--hairline:#ffffff4d;--glass:#ffffff1f;
  --display:44px;--title:22px;--headline:17px;--body:15px;--callout:13px;--footnote:11px;
  --r-badge:5px;--r-row:10px;--r-card:13px;--r-pill:20px;
  --s1:4px;--s2:8px;--s3:12px;--s4:16px;--s5:24px;--s6:32px;--s7:48px;
  --accent:var(--blue);                 /* акцент раздела — один из девяти */
  --glow:color-mix(in srgb,var(--accent) 47%,transparent);
  --tint:color-mix(in srgb,var(--accent) 33%,transparent)}
html{background:var(--black)}
body{margin:0;color:var(--ink);font:var(--headline)/1.35 -apple-system,BlinkMacSystemFont,"SF Pro Text",Inter,system-ui,sans-serif}
```

Вне `:root` писать только `var(--…)`.

## 12. Чек-лист для ИИ перед сдачей

- [ ] Все цвета, размеры шрифта, скругления и отступы — из токенов (поиск по коду: нет «голых» `#hex`, `px`, `dp` вне токенов).
- [ ] Фон чёрный, один акцент на экран.
- [ ] Шесть размеров шрифта, не жирнее Semibold.
- [ ] Два состояния — тумблер, три и больше — выбор.
- [ ] Фокус/нажатие видно.
- [ ] Тексты по-русски, коротко, числа с правильными окончаниями.
- [ ] Желательно: тест, который падает при цвете или размере мимо токенов (как `PaletteTest`/`RemoteTest` в Starwind).

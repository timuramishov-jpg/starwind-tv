# История и решения

Проект сделан за несколько дней (6–8 ноября 2026) вместе с Claude: требования ставил владелец, код писал ИИ, телевизором
он управлял сам через агента на Маке. Здесь — почему сделано так, а не иначе.

## Ход работы

1. **Очистка.** Резервная копия списка пакетов, отключение оболочки Яндекса, его эфира и видеоплеера (`tv slim`).
   Удалять ничего не стали — только `disable-user`.
2. **Свой экран вместо готового лаунчера CleanYourTV.** Владелец хотел строгий стиль Apple: один шрифт (SF Pro), одна
   палитра, док со светом сервиса, живые ленты. Экран переписан с нуля (`Ios*`), от CleanYourTV остались сборка и инструменты.
3. **Дизайн-система и тесты.** После того как цвета «поплыли», все значения собраны в `IosPalette`, а тесты запрещают
   писать цвета и отступы мимо неё. Правило распространено на пульт в телефоне.
4. **Ленты:** YouTube (вход прямо на телевизоре по коду, подписки, фильтр шортсов), ВК, Рутуб, Кинопоиск, Зона.
5. **Скорость и память:** на телевизоре 925 МБ. Убраны аппаратные слои (лаунчер 126 → 83 МБ), обложки в размер,
   дебаунс листания дока, фоновые операции вне главного потока, автоочистка памяти.
6. **Пульт в телефоне.** Сначала сервер жил в лаунчере и умирал, когда система выгружала лаунчер ради YouTube.
   Перенесён в отдельный процесс от имени оболочки (`IosShell`) — пульт работает в любом приложении.
7. **Ввод текста.** Своя клавиатура (`IosKeyboard`) с приёмом текста с телефона; YouTube — через ссылку поиска.
8. **Заставки, таймер сна, источники HDMI, погода, обновление с GitHub без Мака.**
9. **Telegram.** Видео из каналов без входа не достать (t.me отдаёт только «Open in Telegram»). Telegram X оказался
   неуправляемым пультом и тяжёлым — написан свой клиент на TDLib. Ключ API с российского номера получен через VPN
   Казахстана. Потоковая подкачка доведена до старта за секунды. Ленту Telegram в доке попробовали и убрали —
   Telegram остался плеером видео по ссылкам (плитка в ряду приложений).
10. **Пульт по вкладкам:** Пульт / Инструменты / Аккаунты / Состояние; снимок и запись экрана в «Фото» через быструю команду iOS.
11. **Раунд критики (8 ноября).** Рывки при листании убраны (ленивые карточки, свечение одним слоем), добавлена
    проверка `tv smoke`, код разобран (ленты по сервисам — `IosSources`, старый лаунчер CleanYourTV удалён, тесты на GitHub),
    в плеере Telegram — дорожки и субтитры по кнопке Меню и подкачка при перемотке, «Обновить лаунчер» проверено
    на телевизоре. Написан PDF-учебник «с нуля» (`starwind/docs/Starwind-tutorial.pdf`).

## Ключевые решения

| Решение | Почему |
|---|---|
| Ставить по adb, без root и прошивки | Безопасно и обратимо; гарантия и обновления телевизора не страдают |
| Абсолютная вёрстка 1920×1080 в коде | Полный контроль над видом «как Apple TV», без накладных расходов разметки |
| Сервер пульта от имени оболочки | Не умирает при нехватке памяти, мгновенный ввод кнопок, не уходит в VPN |
| Ключи не в APK | APK лежит в открытых релизах GitHub; ключи передаются по adb (`IosConfig`) |
| Свой клиент Telegram, отдельный процесс | Управление пультом, дизайн, память; TDLib не утяжеляет главный экран |
| Telegram только через VPN | Требование владельца; при пропаже туннеля сеть TDLib переводится в «нет сети» |
| Тумблеры и выбор стрелками | Требование владельца: два состояния — тумблер, больше — выбор |
| Быстрая команда iOS для «Фото» | Страница по http не может сохранять в Фото сама |

## Известные ограничения

- Включить телевизор с телефона нельзя (во сне выключается Wi‑Fi).
- Шестерёнку на пульте телевизора перехватывает система Яндекса.
- Перемотка Telegram-видео в нескачанное место — обычно несколько секунд, иногда до 10–20 (TDLib через VPN).
- Поле ввода на пульте не появляется в YouTube (используется поиск ссылкой).
- Шрифты SF не входят в репозиторий (лицензия Apple).
- Обновление «из меню» берёт сборки из `timuramishov-jpg/tv-home` — для чужого телевизора нужен свой репозиторий релизов.

## Идеи

- Поиск по Telegram-каналам и подписка на канал с телевизора.
- Свой порог «длинного видео» в настройках.
- Ленты по времени суток (утром YouTube, вечером фильмы).
- Настройка ленты каждого сервиса долгим ОК (частично есть в меню приложения).
- Скриншоты в документацию — прямо из `tv smoke` (сейчас копируются руками).

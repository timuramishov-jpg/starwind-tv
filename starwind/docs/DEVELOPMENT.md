# Разработка

Как продолжать проект — самому или с любым ИИ-помощником (Claude, ChatGPT/Codex, Gemini, Cursor…). Для ИИ коротко:
**прочитай этот файл, [ARCHITECTURE.md](ARCHITECTURE.md) и [DESIGN.md](DESIGN.md), работай в ветке `starwind`,
после правок — `bash starwind/test/run.sh`, ставь на телевизор через `tv deploy`.**

## Стек

- Android-приложение на **Java** без фреймворков интерфейса: всё рисуется кодом в `FrameLayout` с абсолютными координатами
  макета 1920×1080, пересчёт в пиксели — `px()`. XML-разметки экранов нет.
- Сборка — Gradle (`launcher/`), JDK 17, Android SDK 34. Библиотеки: ZXing (QR), TDLib (Telegram, нативная).
- Пульт — один файл `launcher/app/src/main/assets/remote.html` (ванильный HTML/CSS/JS), отдаётся с телевизора.
- Мак-инструменты — bash (`starwind/tv`), Python 3 (`tools/`), Swift (значки).

## Команды

```bash
bash starwind/test/run.sh             # тесты (Java, без Android) — обязательны перед установкой
~/Documents/Claude/tv deploy          # тесты → сборка → установка → права → домашний экран → отчёт
QUIET=1 ~/Documents/Claude/tv deploy  # то же, но не уводит телевизор с текущего экрана (можно, пока смотрят видео)
RELEASE=0 ~/Documents/Claude/tv deploy # не выкладывать сборку в релизы GitHub (по умолчанию выкладывается)
~/Documents/Claude/tv check           # состояние телевизора; tv report — с журналом лаунчера
~/Documents/Claude/tv log 100         # журнал лаунчера
~/Documents/Claude/tv release         # выложить APK в релизы GitHub — телевизоры обновятся из меню
```

Собрать без установки: `cd launcher && ./gradlew assembleRelease` (нужны `JAVA_HOME` на JDK 17 и `local.properties` с
`sdk.dir`, их готовит `tv setup`).

### `tv deploy` по шагам

1. `online` — телевизор отвечает на `:5555`.
2. `fonts` (шрифты SF из архива), `icons` (SF Symbols через Swift, иначе `starwind/fallback`), `tglibs` (TDLib из
   `starwind/vendor`, сверка SHA‑256).
3. `signing` — ключ `~/Documents/Claude/starwind.jks` (создаётся один раз).
4. Тесты `starwind/test/run.sh` → `./gradlew assembleRelease`.
5. Загрузка APK (`tools/b64push.py`) и `pm install -r`; если ключ подписи другой — предложит переустановку с сохранением настроек.
6. Права, заставка, клавиатура, анимации; перезапуск сервера пульта из нового APK.
7. Та же сборка выкладывается в релизы `timuramishov-jpg/tv-home` (если `gh` вошёл в GitHub, `RELEASE=0` — нет):
   так «Обновить лаунчер» в меню телевизора всегда видит последнюю версию.
8. Без `QUIET`: перезапуск лаунчера, `tv keys`, переход на главный экран, отчёт и снимок экрана.

## Работа с ИИ-помощником

Два режима, которые использовались:

1. **ИИ с доступом к терминалу Мака** (Claude Code, Codex CLI, Cursor и т.п.) — просто выполняет `tv …` и правит файлы.
2. **ИИ в облаке без доступа к домашней сети** (как работал Claude): на Маке запускается агент
   `~/Documents/Claude/tv agent` (окно Терминала оставить открытым; `tv agent install` — автозапуск при входе).
   ИИ кладёт скрипты в `~/Documents/Claude/agent/in/<имя>.sh`, агент выполняет их на Маке (рядом с телевизором) и пишет
   вывод в `agent/out/<имя>.txt`. Код ИИ передаёт пакетом `git bundle` (`starwind.bundle`), который забирает `tv pull`
   (или задание агенту `git fetch ../starwind.bundle starwind && git reset --hard FETCH_HEAD`).

Удобные приёмы при работе с телевизором:
- Снимок экрана быстро: `curl "http://<ТВ>:8687/view?k=<ключ>" -o shot.jpg` (ключ — в
  `/sdcard/Android/data/com.gathin.tvhome/files/remote/key`); полный — `tv shot`.
- Нажать кнопку: `tools/tv.py "input keyevent 23"` или `curl …/key?k=…&c=DPAD_CENTER`.
- Журнал засоряется системой (MediaTek HotKey пишет сотни строк в секунду) — фильтровать по тегу и писать в файл на
  телевизоре: `logcat -v time -s TgSource:I IosHome:* > /data/local/tmp/x.log &`.

## Правила проекта

1. **Дизайн-система — закон.** Цвета, размеры шрифта, скругления, отступы — только токены `IosPalette` (в пульте —
   `var(--…)`). Тесты `PaletteTest`, `SpacingTest`, `RemoteTest` не дадут нарушить. Пульт выглядит так же, как телевизор.
2. **Два состояния — тумблер, больше — выбор** (стрелками на ТВ, списком на пульте).
3. **Тексты интерфейса — по-русски, коротко.** Комментарии в коде — по-русски и объясняют «почему».
4. **Не трогать телевизор вслепую в системных настройках**: цепочка нажатий ОК в системном меню однажды выключила Wi‑Fi
   телевизора. Сначала снимок экрана, потом нажатие.
5. **Обновления катятся тихо** (`QUIET=1`), не прерывая просмотр; новая версия подхватывается при возврате на главный экран.
6. **Ничего не удалять у системы**: только `pm disable-user`, всё обратимо (`tv rollback`, `tv lighten off`).
7. **Ключи — не в git** (`secrets.json`, ключ подписи, ключ Telegram). В репозитории их нет и быть не должно.
8. **Память — главный ресурс** (925 МБ на всё): без аппаратных слоёв, обложки в размер, тяжёлое — в отдельные процессы.
9. Крупные экраны — в отдельные классы (`IosMenu`, `IosCards`, `IosVpn`…); `IosHome` — только каркас, док и навигация.

## Ловушки, на которые уже наступали

| Ситуация | Что знать |
|---|---|
| `pkill -f IosShell` в той же строке, что и запуск | pkill находит свою же командную строку и убивает оболочку. Шаблон `'IosShel[l]'` и отдельной командой |
| Сервер пульта, запущенный по adb, умирает | Запускать из подоболочки `( … nohup setsid app_process … &)` и ждать 1,5 с |
| Кнопка-шестерёнка пульта телевизора | Перехватывается системной службой Яндекса `KeyEventInterceptorService` — перехватить нельзя |
| Службы Яндекса (`io.sdk` ~89 МБ) | Защищены системой, отключить нельзя |
| Выключение с телефона | `KEYCODE_SLEEP` прошивка игнорирует — работает `KEYCODE_POWER`. Включить нельзя: во сне выключается Wi‑Fi |
| Ввод в YouTube | Cobalt не принимает текст через систему — только ссылка на результаты поиска |
| Своя клавиатура после обновления | Система сбрасывает её на Яндекс — `IosRemote` возвращает выбранную |
| Лаунчер подвисает (ANR) | Чтение названий всех пакетов в главном потоке при нехватке памяти — только в фоне и при изменениях |
| TDLib: `libtdjni.so` не грузится | libc++ нужна из NDK r23 (в r27+ нет `__hash_memory`) |
| TDLib: видео стартует минутами | `moov` в конце файла + зависающие куски — см. [TELEGRAM.md](TELEGRAM.md#как-устроена-подкачка-важно-для-доработок) |
| my.telegram.org с российского номера | «ERROR»/«Too many attempts» — VPN Казахстан/Узбекистан, пауза |
| Запись экрана «идёт» сама | Служба MediaTek `vendor.mediatek.tv.screenrecord` похожа по имени — искать процесс `screenrecord` точно (`pidof`) |
| Видео с телевизора в Safari не играет | Нужен ответ с `Range`/`206 Partial Content` |
| «Поделиться» из страницы пульта | Страница по `http://` — не «безопасный контекст», `navigator.share` недоступен; поэтому быстрая команда iOS |
| Telegram X на телевизоре | Не управляется пультом, тяжёлый — заменён своим клиентом |

Как читать

Учебник написан для двух людей: для друга, который повторяет всё на своём телевизоре, и для владельца — на будущее (новый Мак, второй телевизор, сброс телевизора). Шаги 1–5 обязательны и занимают около часа, остальные — по желанию.

Главное правилоНичего на телевизоре не прошивается и не удаляется. Свой экран ставится как обычное приложение, лишнее от Яндекса только выключается. Одна команда tv rollback возвращает всё как было.
Модель телевизораВсё проверено на StarWind SW-LED43SG300 (Яндекс ТВ, Android 11, 1 ГБ памяти). На других телевизорах с Яндекс ТВ / Android TV 8+ почти всё работает так же; могут отличаться пункты системного меню и имена пакетов Яндекса (шаг 6).

Все команды в учебнике набираются в программе «Терминал» на Маке (Программы → Утилиты → Терминал). Строки, начинающиеся с #, — пояснения, их набирать не нужно.

Глава 1

Что получится

Домашний экран в стиле Apple TV вместо оболочки Яндекса, пульт в телефоне и свой плеер видео из Telegram.

Пульт в телефоне

Веб-страница, которую отдаёт сам телевизор. На iPhone сохраняется на экран «Домой» как приложение. Работает в любом приложении на телевизоре: кнопки, кликпад, ввод текста, ссылки, снимок и запись экрана, файлы, настройки.

Ещё

  • Своя экранная клавиатура в том же стиле; текст можно печатать с телефона — поле на пульте появляется само.
  • Таймер сна, блокировка рекламы (частный DNS AdGuard), быстрые анимации, очистка кэша и памяти.
  • VPN (приложение Happ) — тумблер и страна прямо в меню и на пульте.
  • Обновление из меню телевизора — без Мака, из своего репозитория на GitHub.
  • Единая дизайн-система: цвета iOS, шрифт SF Pro, фиксированные размеры. Тесты не дают собрать сборку с цветом или отступом мимо системы.
Глава 2

Как это устроено

Мак собирает программу и ставит её на телевизор по домашней сети. Дальше телевизор живёт сам.

Мак Телевизор (Android, без root) Телефон ┌──────────────────────┐ adb :5555 ┌─────────────────────────────────────────┐ │ команда tv │──────────▶│ com.gathin.tvhome · одно приложение │ │ сборка, тесты, │ │ главный экран, меню, ленты, заставки │ │ установка, ключи, │ │ своя клавиатура │ │ журналы, проверка │ │ Telegram (отдельный процесс) │ └──────────────────────┘ │ сервер пульта (от имени системы) │◀─ HTTP :8687 ─ пульт └─────────────────────────────────────────┘ │ релизы APK ▲ ▼ │ «Обновить лаунчер» GitHub <логин>/tv-home ──────────────────┘
  • Отладка по сети (adb). Мак общается с телевизором по протоколу разработчиков Android на порту 5555. Так ставятся приложения и выдаются права. Root не нужен.
  • Одно приложение. Весь экран — приложение com.gathin.tvhome (выросло из открытого проекта CleanYourTV, экран переписан с нуля). Оно назначается домашним экраном вместо Яндекса.
  • Сервер пульта запускается от имени системной оболочки — поэтому не умирает, когда YouTube съедает память, и мгновенно нажимает кнопки.
  • Ключи не в программе. Ключи YouTube, Кинопоиска и Telegram передаются на телевизор отдельно и не попадают ни в APK, ни в git.
  • Telegram — только через VPN. Если туннеля нет, клиент ставит сеть на паузу.

Шаг 1

Отладка по сети на телевизоре

Разрешаем Маку ставить программы на телевизор. Делается один раз пультом от телевизора.

1
Режим разработчика. Настройки → Устройство → Об устройстве → семь раз нажать ОК на строке «Сборка». Появится «Вы стали разработчиком». На других прошивках ищите «Об устройстве» и номер сборки.
2
Включить отладку. Настройки → Устройство → Для разработчиков → включить Отладка по USB и, если есть, Отладка по сети. На SW-LED43SG300 порт 5555 открывается сразу.
3
Узнать адрес. Настройки → Сеть → Wi‑Fi → своя сеть: адрес вида 192.168.1.50. Запишите его.
4
Закрепить адрес в роутере (резервирование DHCP, раздел «LAN» / «DHCP» в настройках роутера). Иначе через неделю адрес сменится и Мак телевизор не найдёт.
5
При первом подключении телевизор спросит «Разрешить отладку по USB?» с отпечатком ключа — выбрать «Всегда разрешать с этого компьютера» и «ОК». То же окно появится один раз и для самого лаунчера (он тоже подключается к отладке, чтобы чистить кэш и память) — тоже разрешить.
Осторожно с системным менюНе нажимайте ОК «вслепую» в системных настройках: однажды цепочка нажатий выключила телевизору Wi‑Fi, и он пропал из сети. Если такое случилось — включить Wi‑Fi пультом от телевизора.
ПроверкаПосле шага 2 команда ~/Documents/Claude/tv check должна показать модель телевизора и что сейчас на экране. «Телевизор не отвечает» — смотрите главу 16.
Шаг 2

Мак: инструменты и проект

2.1 Homebrew

Менеджер программ для Мака. Если ещё нет — открыть brew.sh, скопировать оттуда одну команду в Терминал, ввести пароль Мака. После установки Homebrew напишет две команды «Next steps» — выполнить их.

# проверка: должна напечатать версию
brew --version

2.2 Получить проект

Репозиторий timuramishov-jpg/starwind-tv закрытый. Два способа:

  • Доступ к репозиторию (удобнее — будут приходить обновления). Тимур добавляет ваш логин GitHub: репозиторий → Settings → Collaborators → Add people. Вы принимаете приглашение из письма.
  • Архив. Тимур присылает папку проекта архивом — распакуйте её в ~/Documents/Claude/cleanyourtv и пропустите git clone ниже.
# GitHub CLI и вход (откроется браузер, войти своим аккаунтом)
brew install gh
gh auth login            # GitHub.com → HTTPS → Login with a web browser

# забрать проект
mkdir -p ~/Documents/Claude
gh repo clone timuramishov-jpg/starwind-tv ~/Documents/Claude/cleanyourtv

2.3 Подготовить Мак одной командой

~/Documents/Claude/cleanyourtv/starwind/tv setup

tv setup один раз ставит Java 17, Android SDK (platform 34, build-tools 34), окружение Python для связи с телевизором, спрашивает адрес телевизора (из шага 1) и создаёт короткую команду ~/Documents/Claude/tv. Это самый долгий шаг — 15–30 минут загрузки.

Проверка~/Documents/Claude/tv check — модель телевизора, домашний экран, память. Работает? Идём дальше.

Удобно добавить команду в путь, чтобы писать просто tv: echo 'export PATH="$HOME/Documents/Claude:$PATH"' >> ~/.zshrc и открыть новое окно Терминала. Дальше в учебнике — коротко tv ….

Шаг 3

Шрифты SF Pro

Весь интерфейс рассчитан на шрифт Apple SF Pro. В репозиторий он не входит — лицензия Apple.

  1. Скачать шрифты бесплатно: developer.apple.com/fonts → SF Pro.
  2. Положить архив в ~/Documents/Claude/ с именем вида SF-NF-*.zip (внутри — TTF/SFNS-*.ttf). tv deploy сам возьмёт Light / Regular / Medium / Semibold и широкое начертание для заставки.
  3. Если архив устроен иначе — положить руками четыре файла в launcher/app/src/main/res/font/: sf_light.ttf, sf_regular.ttf, sf_medium.ttf, sf_semibold.ttf.

Скруглённые цифры заставки и значки шапки берутся с самого Мака (нужно xcode-select --install), иначе — готовые из проекта.

Можно пропуститьБез архива сборка тоже пройдёт: поставится свободный шрифт-замена Inter (с кириллицей, выглядит почти так же). Положите архив SF позже — следующий tv deploy переключит шрифт.
Шаг 4

Ключи сервисов (по желанию)

Нужны для лент YouTube и Кинопоиска. Без них всё работает, просто эти две ленты будут пустыми. ВК, Рутуб и погода ключей не требуют.

Создайте файл ~/Documents/Claude/secrets.json:

{
  "installed": { "client_id": "….apps.googleusercontent.com", "client_secret": "…" },
  "api_key": "AIza…",
  "kinopoisk_key": "…",
  "twitch_client_id": "…"
}
КлючГде взять
installed (вход в YouTube, лента подписок)console.cloud.google.com → новый проект → APIs & Services → Library → YouTube Data API v3 → Enable. Затем Credentials → Create credentials → OAuth client ID → тип TVs and Limited Input devices. Скачанный JSON уже имеет вид {"installed": …} — скопируйте его блок в файл.
api_key (популярное и поиск)Там же: Credentials → Create credentials → API key.
kinopoisk_keykinopoiskapiunofficial.tech — бесплатный ключ после регистрации.
twitch_client_id (лента Twitch)dev.twitch.tv/console/apps → Register Your Application: название любое, OAuth Redirect URL http://localhost, Client Type — Public (в аккаунте Twitch нужна двухфакторная защита). Можно не класть в файл, а ввести в пульте: «Аккаунты» → Twitch.
Ключи — никогда не в gitФайл лежит только в рабочей папке. tv deploy передаёт ключи на телевизор по сети, в программу они не попадают. Передать заново: tv keys.
Шаг 5

Первая установка

tv deploy

Одна команда делает всё. По шагам:

#Что происходит
1Проверяет, что телевизор в сети; готовит шрифты, значки, библиотеку Telegram (сверяет контрольные суммы).
2Создаёт ключ подписи ~/Documents/Claude/starwind.jks (один раз). Его нужно сохранить — см. главу 18.
3Прогоняет тесты дизайн-системы и разборщиков лент. Не прошли — не собирает.
4Собирает приложение (Gradle), загружает на телевизор и ставит.
5Выдаёт права: системные настройки, таймер сна, заставка, установка обновлений, своя клавиатура, быстрые анимации.
6Запускает сервер пульта, делает лаунчер домашним экраном, передаёт ключи.
7Выкладывает сборку в ваш репозиторий релизов на GitHub (для обновлений из меню, глава 13).
8Переходит на главный экран и показывает отчёт со снимком экрана.

Первая сборка идёт 3–6 минут (Gradle скачивает зависимости), следующие — 1–2 минуты.

Что увидите на телевизореОкно «Разрешить отладку?» от самого лаунчера — разрешить «всегда». Затем главный экран с доком. Пока нет ключей, ленты YouTube и Кинопоиска пустые — это нормально.

Проверить, что всё работает

tv smoke

tv smoke сам пройдёт по экранам (главный, лента, док, настройки, поиск, приложения, заставка, Telegram), снимет каждый в ~/Documents/Claude/smoke/<время>/, замерит плавность и проверит, нет ли падений. В конце — «РЕЗУЛЬТАТ: всё в порядке». Если на телевизоре в это время что-то смотрят, проверка не запустится (FORCE=1 tv smoke — всё равно).

Шаг 6

Убрать Яндекс с глаз и разгрузить память

На телевизоре всего ~1 ГБ памяти, и оболочка Яндекса держит её постоянно. Выключаем (не удаляем):

tv slim       # выключить оболочку Яндекса, его эфир и видеоплеер
tv lighten    # запретить фоновую работу лишним приложениям

Всё обратимо: tv lighten off, tv rollback (Яндекс снова домашний экран).

Другая модель телевизораtv slim выключает пакеты com.yandex.tv.home, com.yandex.tv.input.efir, com.yandex.tv.videoplayer, com.yandex.devices.farm.companion. На другой прошивке имена могут отличаться — посмотреть список: tv check или попросить ИИ (глава 15). Системные службы Яндекса (io.sdk) выключить нельзя — система их защищает, это нормально.
Шаг 7

Приложения и VPN

Док по умолчанию: YouTube, ВК Видео, Рутуб, Кинопоиск, Зона (если стоит), Happ. Ставить приложения:

  • с Мака: tv install файл.apk;
  • с телефона: пульт → «Инструменты» → «Отправить на телевизор» (APK ставится сразу);
  • магазины: tv aurora (Aurora Store — Google Play без аккаунта; так ставится Twitch) или RuStore.
ПриложениеЗачемПакет
HappVPN для всего телевизора; лаунчер управляет им из меню и пультаsu.happ.proxyutility
ВК Видео, РутубЛенты в докеcom.vk.tv, ru.rutube.app.tv
ЗонаФильмыru.zonaplayer.app
TwitchЭфиры подписок и записи; лаунчер сам поставит его в докtv.twitch.android.app

Порядок дока меняется прямо на телевизоре: кнопка «Меню» на приложении → «Переместить» (см. снимок в главе 1).

VPN. В Happ добавить свою подписку (ссылку от поставщика VPN). Включается тумблером в меню Wi‑Fi на телевизоре или на пульте. tv route on — через VPN только YouTube и Google, tv route off — весь трафик.

Шаг 8

Пульт в телефоне

1
На главном экране телевизора — значок телефона вверху справа (или Настройки → «Пульт в телефоне»). Появится QR-код.
2
Навести камеру телефона, открыть ссылку вида http://192.168.x.x:8687/?k=КЛЮЧ.
3
iPhone: «Поделиться» → «На экран „Домой“». Появится иконка Starwind, пульт открывается как приложение. Ключ запоминается.
Пароля нет — так задуманоПульт рассчитан на домашнюю сеть. Ключ k — случайная строка, без него сервер ничего не делает. Не публикуйте ссылку с ключом.

Что умеет

ВкладкаЧто там
ПультДок сервисов, кликпад, назад / домой / пауза / громкость / выключить, поиск, поле ввода (появляется само, когда на телевизоре открыта клавиатура), «Открыть на телевизоре» — ссылка YouTube, ВК, Рутуб, Telegram, любой сайт; VPN.
ИнструментыСнимок и запись экрана, заставка, освободить память, файлы на телевизоре (фильмы, APK, загрузки), настройки телевизора тумблерами и списками, очистка кэша, перезагрузка.
АккаунтыYouTube и Twitch — войти/выйти кодом на экране телевизора (для Twitch сначала Client ID), Telegram — ключ, вход по QR, пароль, Яндекс.
СостояниеПроцессор, память, температура, сеть, место; кто занимает память; все приложения — остановить, очистить, отключить, удалить.

Снимки и запись в «Фото» (iPhone). Страница по http:// не может сама сохранять в «Фото», поэтому есть быстрая команда «Starwind в Фото»: пульт → «Инструменты» → «Установить команду „Starwind в Фото“» → открыть файл → «Добавить быструю команду», затем включить «Сразу сохранять в Фото». При первом сохранении разрешить доступ к Фото и локальной сети.

Включить телевизор с телефона нельзя: во сне он выключает Wi‑Fi. Выключить — можно (красная кнопка).

Шаг 9

Telegram (по желанию)

Свой клиент на официальной библиотеке Telegram (TDLib): видео из постов на большом экране, без переписки.

1
Ключ API. my.telegram.org → войти по номеру → «API development tools» → создать приложение (название любое, платформа Android). Взять api_id (число) и api_hash (32 символа).
Российский номерСайт часто отвечает «ERROR» или «Too many attempts». Помогает VPN через Казахстан или Узбекистан и пауза в несколько часов. Можно взять ключ у человека с другим номером — он не даёт доступа к его аккаунту, входите вы своим.
2
Ввести ключ в пульте: «Аккаунты» → Telegram → api_id, api_hash → «Сохранить». Ключ уходит прямо на телевизор, на Маке и в git его нет.
3
Войти. «На экран» — на телевизоре QR-код. На телефоне: Telegram → Настройки → Устройства → Подключить устройство → навести камеру. Облачный пароль, если есть, пульт попросит отдельно.
4
Смотреть. В Telegram на телефоне «Поделиться» → «Копировать ссылку» на пост с видео, в пульте «Открыть на телевизоре» → вставить. Или плитка Telegram в ряду приложений → «Мои каналы».

Большие видео (1–2 ГБ) не скачиваются целиком: подкачивается кусок вокруг места просмотра, старт — за несколько секунд. Задержитесь на карточке секунду перед ОК — начало и конец файла подготовятся заранее. Весь трафик Telegram — только через VPN; если VPN выключен, клиент покажет «Нет VPN».

Шаг 10

Обновления

С Мака

tv update      # забрать свежий код с GitHub
tv deploy      # собрать и поставить
QUIET=1 tv deploy   # тихо: не уводит телевизор с текущего экрана, можно во время просмотра

Из меню телевизора, без Мака

Каждая сборка tv deploy выкладывается в ваш открытый репозиторий релизов <ваш логин>/tv-home (создаётся сам, в нём только APK, без ключей). На телевизоре: шестерёнка → «Обновить лаунчер». Телевизор скачает сборку и один раз спросит «Установить?» — выбрать «Установить».

Почему у каждого свой репозиторийСборки подписаны ключом владельца (starwind.jks). Сборка Тимура на ваш телевизор не встанет, и наоборот. Поэтому обновления — только из своего репозитория. Нужен лишь вход gh auth login (шаг 2). Не вошли — пункт меню скажет «не настроено», остальное работает.

Правила проекта (помощник должен их знать)

  3. Тексты по-русски и коротко.

Если что-то не так

ПроблемаЧто сделать
«Телевизор не отвечает»Включён и в той же сети? Не сменился адрес (~/Documents/Claude/tv-ip)? Отладка включена? Закрепите адрес в роутере.
Телевизор просит «Разрешить отладку?»Разрешить и отметить «Всегда».
Пульт не открываетсяТелефон в той же Wi‑Fi? Открыть QR заново. Не помогло — QUIET=1 tv deploy перезапустит сервер пульта.
На пульте нет поля вводаВключена ли своя клавиатура (Инструменты → «Своя клавиатура»)? В YouTube поля нет — там поиск лупой пульта.
Ленты YouTube / Кинопоиска пустыеНет ключей (шаг 4, потом tv keys). Подписки YouTube — войти: пульт → Аккаунты → YouTube.
Экран подвисаетНе хватает памяти: tv lighten, плитка «Очистить память». tv report покажет, кто занимает память.
Twitch: «Нужен Client ID»Шаг 4: своё приложение на dev.twitch.tv (тип Public), Client ID — в пульт.
Telegram «Нет VPN»Так задумано — включить Happ.
Telegram «Ключ не подошёл»api_id — число, api_hash — 32 символа (a–f, 0–9).
UPDATE_INCOMPATIBLE при установкеСборка подписана другим ключом (потерян starwind.jks). Согласиться на переустановку — настройки вернутся из копии.
«Обновить лаунчер»: «не настроено»Сборка сделана без входа в GitHub: gh auth login, затем tv deploy.
Сборка падаетЖурнал — ~/Documents/Claude/build.log, тесты — test.log. Частое: нет Java 17 / SDK — tv setup.
Заставка не включаетсяПульт → Инструменты → «Заставка через»; простой на главном экране должен быть дольше задержки.
Таймер сна не гасит экранtv deploy выдаёт права администратора; посмотреть, не было ли там ошибки.

Известные ограничения

  • Включить телевизор с телефона нельзя (во сне Wi‑Fi выключен).
  • Кнопку-шестерёнку на пульте телевизора перехватывает система Яндекса.
  • В YouTube текст с телефона не вводится — поиск идёт ссылкой.
  • Перемотка Telegram-видео в нескачанное место — обычно несколько секунд, иногда до 10–20.
